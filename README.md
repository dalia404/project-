# Pulsar Observation Data Clustering System

An unsupervised machine learning project for discovering patterns in unlabeled pulsar observation data using K-Means clustering.

The project focuses on preprocessing, feature engineering, clustering, and quantitative cluster evaluation.

---

## Overview

Pulsar datasets can contain multidimensional signal characteristics that are difficult to analyze manually.

This project applies unsupervised learning to identify meaningful groups within unlabeled observations.

---

## Objectives

- Clean and preprocess observation data
- Engineer informative signal features
- Reduce the effect of noise
- Apply unsupervised clustering
- Evaluate cluster quality
- Analyze relationships between observations
